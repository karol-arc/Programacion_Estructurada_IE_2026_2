# Proyecto de Inventarios
##	Validación Integral de Operadores: Al vender un producto (restar cantidad del vector inventario), validar con condicionales lógicos que la cantidad solicitada no exceda el stock actual.



1. Crear un vector llamado inventario con 5 posiciones
2. Asignar las cantidades iniciales del inventario
3.  Mostrar las cantidades disponibles de cada producto
4. Solicitar el producto que quieres vender
5. Leer producto
5. Solicitar la cantidad de producto que deseas vender
6. Leer cantidad
7. SI cantidad > 0 Y cantidad <= inventario[producto] 
ENTONCES inventario[producto] = inventario[producto] - cantidad
8. Se realiza la compra
9. Se resta el producto del inventario
10. Se imprime el inventario actualizado
11. Fin.
