# Sistema de Gestión Escolar	
## Búsqueda Secuencial (Arreglos): Tener un vector con los nombres y otro con las calificaciones (Arreglos Paralelos). Pedir un nombre, buscarlo con un ciclo y mostrar si aprobó o reprobó.




1. Declarar y dimensionsar los arreglos (nombres y calificaciones)
2. Llenar la información inicial 
3. Se establece la calificacion aprobatoria 
4. Se ingresa el nombre del alumno del que se quiera saber la informacion
5. Se imprime si el alumno aprobo o reprobo
6. Fin
